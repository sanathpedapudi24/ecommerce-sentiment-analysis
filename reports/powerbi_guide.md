# Power BI Dashboard Setup & Usage Guide

## Artifacts Provided
- **Dashboard File**: `reports/sentiment_dashboard.pbix`
- **Custom Theme**: `reports/theme.json`
- **Data Source**: CSV files in `reports/exports/` (generated by `make export` / `uv run python -m src.cli export`)

---

## 1. Data Connection Architecture
The dashboard imports seven CSV files from `reports/exports/`, one table each. Whenever new predictions or reviews are ingested, running `make export` updates the CSV files. Refreshing Power BI updates every visual with a single click.

Import only the seven short-named files below. Each `vw_*.csv` is an identical copy kept for SQL-view naming. Don't use the **Folder → Combine** option: the files have different columns, so combining them produces one broken table.

### Imported Tables (7 Views)
| Power BI Table Name | CSV Source Path | SQL View Origin |
|---|---|---|
| `overview` | `reports/exports/overview.csv` | `vw_sentiment_overview` |
| `by_department` | `reports/exports/by_department.csv` | `vw_sentiment_by_department` |
| `rating_vs_predicted` | `reports/exports/rating_vs_predicted.csv` | `vw_rating_vs_predicted` |
| `negative_reviews` | `reports/exports/negative_reviews.csv` | `vw_negative_reviews` |
| `model_performance` | `reports/exports/model_performance.csv` | `vw_model_performance` |
| `api_usage` | `reports/exports/api_usage.csv` | `vw_api_usage` |
| `top_terms` | `reports/exports/top_terms.csv` | `vw_top_terms` |

## 2. Power Query (M) Setup

Power BI needs an **absolute** file path, and review text contains commas and quotes, so CSV quoting must be on (`QuoteStyle.Csv`). Use one folder parameter so that moving the files (for example to OneDrive, see §6) is a single change.

1. **Home → Transform data → Manage parameters → New**: name `ExportsFolder`, type **Text**, current value is the full path to the exports folder **with a trailing backslash**, e.g.
   `C:\Users\<you>\Downloads\ecommerce-sentiment-analysis\reports\exports\`
2. **Home → New source → Blank query → Advanced Editor**, paste the function below, and rename the query `LoadExport`:

   ```powerquery
   (fileName as text) as table =>
   let
       Source = Csv.Document(
           File.Contents(ExportsFolder & fileName),
           [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]
       ),
       Headers = Table.PromoteHeaders(Source, [PromoteAllScalars = true])
   in
       Headers
   ```

3. Create one blank query per table, named as in the table above, with these contents:

   ```powerquery
   // overview
   Table.TransformColumnTypes(LoadExport("overview.csv"),
       {{"label", type text}, {"review_count", Int64.Type}, {"pct", type number}})
   ```
   ```powerquery
   // by_department
   Table.TransformColumnTypes(LoadExport("by_department.csv"),
       {{"department_name", type text}, {"class_name", type text}, {"predicted_label", type text},
        {"review_count", Int64.Type}, {"avg_rating", type number}})
   ```
   ```powerquery
   // rating_vs_predicted
   Table.TransformColumnTypes(LoadExport("rating_vs_predicted.csv"),
       {{"rating", Int64.Type}, {"predicted_label", type text}, {"review_count", Int64.Type}})
   ```
   ```powerquery
   // negative_reviews
   Table.TransformColumnTypes(LoadExport("negative_reviews.csv"),
       {{"review_id", Int64.Type}, {"department_name", type text}, {"class_name", type text},
        {"title", type text}, {"review_text", type text}, {"confidence", type number}})
   ```
   ```powerquery
   // model_performance
   Table.TransformColumnTypes(LoadExport("model_performance.csv"),
       {{"model_version", type text}, {"algorithm", type text}, {"accuracy", type number},
        {"macro_f1", type number}, {"trained_at", type datetime}, {"is_active", Int64.Type}})
   ```
   ```powerquery
   // api_usage
   Table.TransformColumnTypes(LoadExport("api_usage.csv"),
       {{"date", type date}, {"label", type text}, {"request_count", Int64.Type}, {"avg_confidence", type number}})
   ```
   ```powerquery
   // top_terms
   Table.TransformColumnTypes(LoadExport("top_terms.csv"),
       {{"label", type text}, {"term", type text}, {"weight", type number}, {"rank", Int64.Type}})
   ```

4. Right-click `ExportsFolder` and `LoadExport` → uncheck **Enable load** (they are helpers, not tables), then **Close & Apply**.

`api_usage.csv` only has rows after the API has served requests and `make export` has run again. Until then, the page 4 traffic charts are empty.

## 3. DAX Measures

The following key measures are defined for cross-page metrics and KPI cards:

```dax
Total Reviews = SUM(overview[review_count])

Negative % = DIVIDE(CALCULATE([Total Reviews], overview[label]="negative"), [Total Reviews], 0)

Positive % = DIVIDE(CALCULATE([Total Reviews], overview[label]="positive"), [Total Reviews], 0)

Neutral %  = DIVIDE(CALCULATE([Total Reviews], overview[label]="neutral"), [Total Reviews], 0)

// Weighted by review count: a plain AVERAGE of group averages would overweight small classes
Avg Rating = DIVIDE(
    SUMX(by_department, by_department[avg_rating] * by_department[review_count]),
    SUM(by_department[review_count])
)

Negative Share by Class = DIVIDE(
    CALCULATE(SUM(by_department[review_count]), by_department[predicted_label]="negative"),
    CALCULATE(SUM(by_department[review_count]), ALL(by_department[predicted_label]))
)
```

## 4. Dashboard Pages & Layout

### Page 1: Executive Overview
- **Top KPI Cards**: Total Reviews (22,640), Positive % (77.1%), Neutral % (12.5%), Negative % (10.5%), Average Rating (4.18 / 5.0).
- **Donut Chart**: Sentiment share distribution (Positive = Dark Teal `#006D77`, Neutral = Mid Grey `#6C757D`, Negative = Accent Red `#D90429`).
- **Stacked Bar Chart**: Review volume by department split by sentiment.
- **Top Slicers**: Department Name, Division Name, Class Name (synced across pages).

### Page 2: Category Drill-down
- **100% Stacked Bar**: Sentiment distribution across all 20 clothing classes.
- **Department x Class Matrix**: Total volume, average rating, and % negative with conditional formatting highlighting product lines with elevated negative sentiment.
- **Scatter Plot**: Average Rating (X) vs % Negative (Y), bubble size proportional to review count.

### Page 3: Text Insights
- **Clustered Bar Chart**: Top 10 high-frequency terms for positive, neutral, and negative sentiment from `top_terms`.
- **Confusion Heatmap**: Matrix visual cross-tabulating Customer Rating (1 to 5) vs Predicted Sentiment Label.
- **Review Inspector Table**: Sortable table of lowest-confidence reviews and severe negative feedback from `negative_reviews`.

### Page 4: Model Monitoring & Operations
- **Header KPI Cards**: Active Model Version (`v1.1.0`), Test Accuracy (`0.8289`), Test Macro-F1 (`0.6602`).
- **Registry Table**: Historical and candidate model runs with validation and test metrics (`model_performance`).
- **Time Series Line Chart**: API request volume per day segmented by predicted label.
- **Confidence Trend Line Chart**: Mean prediction confidence per day for operational drift detection.

## 5. Verification Checklist

1. **Total Review Count**: Equals exactly `22,640` (matching `SELECT COUNT(*) FROM reviews`).
2. **Design Consistency**: Neutral grey background `#F8F9FA`, Segoe UI font, zero 3D/gradients, consistent sentiment colors.
3. **One-Click Refresh**: Executing `make export` followed by clicking **Refresh** in Power BI updates all visuals without altering column mappings.

## 6. Sharing & Cloud Options

| Goal | What to do | Needs |
|---|---|---|
| Build and demo on your own PC | Power BI Desktop with `ExportsFolder` pointing at the full path of `reports\exports\`. Save as `reports/sentiment_dashboard.pbix`. | Power BI Desktop (free, Windows) |
| Share it as a file | Send the `.pbix`; others open it in Power BI Desktop. The data is embedded at the last refresh. | Nothing extra |
| View it online | In Desktop, **Home → Publish → My workspace** opens it at app.powerbi.com. | A Microsoft **work or school** account; a free licence covers *My workspace*, while sharing with others needs Power BI Pro (a trial is available) |
| Refresh online without your PC | Export the CSVs into a synced OneDrive for work or school / SharePoint folder, point `ExportsFolder` at that synced path, then publish. | Work or school OneDrive / SharePoint |
| Refresh online straight from this folder | Install the **on-premises data gateway (personal mode)** on this PC and set a refresh schedule for the dataset in the service. | The PC must be on at refresh time |

To export straight into a synced cloud folder:

```bash
uv run python -m src.cli export --output-dir "C:\Users\<you>\OneDrive - <Org>\sentiment-exports"
```

Avoid **Publish to web** for this report: it makes the report public to anyone with the link, including the customer review text in `negative_reviews`.
