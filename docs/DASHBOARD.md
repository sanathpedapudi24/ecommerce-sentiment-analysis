# Power BI Dashboard

File: `reports/sentiment_dashboard.pbix`. Power BI Desktop (Windows).

## Data source

Primary: CSV exports of SQL views in `reports/exports/` (generated by `make export`), loaded with the folder connector so refresh is one click. Optional: direct SQLite via ODBC driver.

Imported tables: `overview`, `by_department`, `rating_vs_predicted`, `negative_reviews`, `model_performance`, `api_usage`, `top_terms`.

## Pages

### 1. Executive Overview
- KPI cards: Total Reviews, % Positive, % Neutral, % Negative, Average Rating
- Donut: sentiment share
- Bar: reviews by department, split by sentiment
- Slicers: Department, Class, Division

### 2. Category Drill-down
- 100% stacked bar: sentiment by Class Name
- Matrix: Department × Class with % negative and conditional formatting
- Scatter: average rating vs % negative, one point per class, size = review count

### 3. Text Insights
- Top 10 terms per sentiment (bar charts from `top_terms`)
- Table: lowest-confidence negative reviews (from `negative_reviews`), sortable
- Heatmap: actual rating (1–5) vs predicted label

### 4. Model Monitoring
- Cards: active model version, accuracy, macro-F1
- Table: all model versions with metrics
- Line: API requests per day, by predicted label
- Line: average prediction confidence per day

## DAX measures

```DAX
Total Reviews = SUM(overview[review_count])
Negative % = DIVIDE(CALCULATE([Total Reviews], overview[label]="negative"), [Total Reviews])
Positive % = DIVIDE(CALCULATE([Total Reviews], overview[label]="positive"), [Total Reviews])
Neutral %  = DIVIDE(CALCULATE([Total Reviews], overview[label]="neutral"), [Total Reviews])
Avg Rating = AVERAGE(by_department[avg_rating])
```

## Design rules

- Neutral grey/white canvas, one accent colour for negative sentiment, muted tones for the rest
- Sentiment colours consistent on every page (positive = dark teal, neutral = mid grey, negative = accent)
- Single typeface, left-aligned titles, no 3-D, no gradients, no decorative icons
- Maximum 6 visuals per page; every visual has a title stating what it shows
- Tooltips enabled; slicers synced across pages 1–3

## Acceptance

- All four pages render with no errors
- Totals on Page 1 equal `SELECT COUNT(*) FROM reviews`
- Refreshing after `make export` updates every visual without editing queries
